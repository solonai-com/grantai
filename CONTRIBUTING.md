# Contributing to GrantAi

Thank you for your interest in GrantAi.

## How to Contribute

### Reporting Issues

Found a bug or have a feature request? [Open an issue](https://github.com/solonai-com/grantai/issues) with:

- **Bug reports**: Steps to reproduce, expected vs actual behavior, platform/version info
- **Feature requests**: Use case, why it matters, any implementation ideas

### Questions and Discussion

- **General questions**: Open an issue with the `question` label
- **Email**: support@solonai.com

### Feedback

We actively read all issues and feedback. Your input directly shapes the product roadmap.

## Code Contributions

GrantAi is proprietary software. We don't accept code contributions at this time.

However, we welcome:
- Bug reports
- Documentation improvements (typos, clarity, examples)
- Feature suggestions
- Integration ideas (new MCP clients, frameworks)

## Security

If you discover a security vulnerability, please email security@solonai.com directly. Do not open a public issue.

## Community Guidelines

- Be respectful
- Be constructive
- Help others when you can
